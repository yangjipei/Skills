# PRD 第 7～11 章编写规则

- **7 异常场景**：写明触发条件、系统处理、用户提示和后续动作。未确认的重试次数、时间和策略不得自行补充。
- **8 数据指标**：写明指标名、业务定义、公式、维度、数据来源、周期、基线和目标值。未确认的基线、目标值或口径写入待确认问题。
- **9 验收标准**：用可验证的前置条件、操作和预期结果覆盖主流程、关键异常、权限和边界。
- **10 风险与影响范围**：写明对业务、客户、数据、现有流程、上下游、运营和多国家/多产品的影响，以及风险触发条件、程度和已确认应对方案。
- **11 待确认问题**：只保留不阻塞 PRD 交付的问题，沿用 `Qxxx` 编号，写明影响和责任人；阻塞问题在生成 PRD 前解决。
