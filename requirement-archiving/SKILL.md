# 需求归档与重开

先读[阶段产物与交接协议](../_shared-requirement-protocol.md)，再读取[归档与重开规则](references/workflow-archive.md)。

## 职责

- 接受既有需求目录或用户指定的等效结果集；核对当前基线、已约定交付范围及完成状态，不要求结果由本流水线生成。
- 保留有效成果、最终评审结论与相关原始参考资料；未执行、不适用或无法核实的阶段如实记录，不补造完成状态。
- 按用户已明确给出的归档或重开授权移动目录，不重复索取同一授权；同一需求只保留一个有效目录。
- 清理工作稿、历史版本或已被完整吸收的过程材料前，列出目标、用途和影响并获得明确确认；未获准时保留并标为待清理。
- 续作入口统一为 `00-需求信息.md`；所有需求重开都使用当前流程，保留编号，按本次变更范围读取有效成果并直接交接专业 Skill。索引缺失时按当前协议补齐，不恢复旧执行规则。

## 边界

只整理结果、索引及目录，不生成或评审需求内容。缺少业务定义或需要改 PRD 链接时交回责任 Skill。归档不代表上线，也不自动启动手册生成。正常执行不读取 `_shared-wiki`。
