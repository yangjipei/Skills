# 需求归档与重开

先读[阶段产物与交接协议](../_shared-requirement-protocol.md)，再读取[归档与重开规则](references/workflow-archive.md)。

## 职责

- 接受既有需求目录或用户指定等效结果集；按实际执行范围核对有效基线。
- 保留当前有效 `01-需求分析.md`、必要流程、Page IA / Spec / 原型、PRD、评审和相关原始参考资料。
- 未执行、不适用或无法核实的阶段如实记录，不为了归档补造产物。
- 清理工作稿、旧版本或过程材料前列出目标、用途和影响，并获得明确确认。
- 重开时只读取 `00-需求信息.md` 和本次受影响 S/P/M/章节，直接交对应专业 Skill；不重跑整条链路。

## 边界

只整理结果、索引和目录，不生成或评审需求内容。归档不代表上线，也不自动启动操作手册。正常执行不读取 `_shared-wiki`。
